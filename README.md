# STAT207-Soccer-Data-Analysis

### Overview

This contains projects completed for STAT 207: Data Science Exploration at the University of Illinois Urbana-Champaign.

The projects explore soccer player market values, player characteristics, and injury-related factors using Python.

### Projects

#### Project 1: Exploratory Data Analysis

Cleaned and explored soccer player data.

Compared market values across player positions.

Created visualizations and descriptive statistical summaries.

#### Project 2: Statistical Inference

Constructed confidence intervals for injury-related proportions.

Conducted hypothesis tests involving player market values.

Interpreted statistical findings using p-values and confidence intervals.

### Tools

-Python

-Pandas

-Matplotlib

-Seaborn

-Statistical inference methods

### Contributions

Projects 1 & 2: Originally submitted as group assignments, but all Python programming, statistical analyses, visualizations, and written interpretations were independently completed by me.

Project 3: Completed collaboratively as a group project, involving regression modeling, model evaluation, and interpretation of results.
